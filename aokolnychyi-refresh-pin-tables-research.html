Table ID (implemented) vs Column ID (not yet)

FileLinesDescription
sql/catalyst/.../connector/catalog/Table.java 53-61 Table.id() - returns table ID (null by default, connectors opt-in). Used for drop+recreate detection.
Column ID: The design doc mentions "introducing the notion of column ID in Spark" as future work (targeted for 4.2). Currently Spark resolves columns by name only. Iceberg and Delta track column IDs internally but Spark does not consume them at the DSv2 API level. No PRs exist for this yet.
